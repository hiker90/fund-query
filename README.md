# FundPilot · 基金策略管家

基于「一次性建仓 + 闲置资金补仓」策略的移动端基金监控工具。纯静态页面，无需后端，可直接托管在 GitHub Pages；所有数据保存在本机浏览器。

## 功能

- **基金监控**：手动添加 6 位基金代码，自动补全名称与最新净值，也可以完全手动录入。
- **交易策略**：内置「普通 / 激进」双预置方案，在策略页对比参数并一键切换全局默认；单基金可覆盖为普通、激进或不启用（不启用仅记录成本，不计算止损/止盈/分档线）。普通：止损 12%、20% 止盈卖出 40%、8% 移动止盈、5%/10%/15% 三档递增补仓；激进：止损 8%、25% 止盈卖出 50%、10% 移动止盈、4%/8%/12% 三档递增补仓
- **今日关注汇总卡**：持仓页自动聚合全部持仓的止损/移动止盈/止盈/可补仓/接近止损状态，按严重度排序，一眼知道今天要做什么
- **定投计划**：基金详情页可为单只基金设置每日或每周（周一~周五任选一天）自动定投；刷新净值或打开应用时自动为已出净值的交易日累计买入（周末与节假日自动跳过），持仓金额与收益率实时并入计算；随时可更改频率/金额，自下一执行期生效、不影响已有买入；停止定投时累计自动并入交易记录。定投数据为聚合存储（累计份额+金额），不随时间膨胀
- **交易明细**：持仓页顶栏图标进入，全部基金交易流水按时间倒序按月分组一览，支持买入/卖出筛选，点击记录直达基金详情
- **宏观方向推荐（债券/黄金/海外基金）**：这三类基金不适用分档策略，改按宏观指标自动给方向——债券看中债期限利差（≤30bp 宜增配 / ≥60bp 控久期）、黄金与海外（QDII）看美债实际利率（≤0 宜增配 / ≥2 宜减配，海外叠加曲线倒挂警示）；权益类基金默认标准策略且可手动覆盖
- **净值走势**：基金卡片内嵌近 60 个采样点的迷你走势线（纯 SVG），涨红跌绿，一眼看清趋势
- **策略回测**：策略页选一只持仓基金 + 普通/激进方案，用本地净值快照回放策略自动执行效果，输出区间收益/最大回撤/触发次数，并与买入持有对比
- **成本管理**：买卖流水记账、摊薄成本、剩余份额、持仓市值、浮盈与已实现收益；每次补仓后按新的平均成本重新计算止损线与止盈线。当日买入的份额按成交净值（当日收盘净值）计算市值，不参与当日涨跌
- **交易暂存**：当日净值尚未公布时登记的买入/卖出会先暂存（交易明细带「待净值」徽标），不参与持仓金额与收益率计算；净值更新后（刷新净值 / 手动录入 / 打开应用）自动按当日净值确认——买入算出份额、卖出算出金额，周末与节假日暂存的记录顺延至下一交易日净值确认
- **三资产自动归类**：添加/批量导入基金后按东财 F10 基金类型（FTYPE）自动归入权益/债券/黄金大类（含「债券」→ 债券，含「黄金」→ 黄金，其余 → 权益），大类完全自动、无手动指定；基金卡片展示 FTYPE 原值
- **估值水平标签**：按基金类型分流——债券基金用中债10Y收益率分位取反（收益率低=债贵）、黄金基金用 COMEX 金价分位、指数股票基金用跟踪指数价格分位；主动/行业/QDII 基金不显示。≤30% 低估、30–70% 正常、≥70% 高估，约 2 年窗口，30 分钟内存缓存，接口失败不显示
- **宏观观察**：顶部权益/债券/黄金/石油四行方向速览；股债性价比（含 1÷PE 换算明细）、美国实际利率（近似）、美/中期限利差（10Y−2Y）、通胀与景气（CPI/PPI/PMI，月度）、黄金（含美元指数）、原油，每个核心指标一张卡片并给出一句话资产平衡方向。
- **三资产再平衡**：配置页分「三资产」（默认：目标比例完全由宏观推荐方案自动决定——进攻/平衡/偏金/防守，行内可展开基金明细，大类由基金类型自动归类）与「自定义分类」（自管标签与权重）两个标签。
- **补仓模拟器**：输入拟补金额与成交净值，立即看到新成本、新止损线、新止盈线和成本下降幅度。
- **按需刷新净值**：进入持仓页自动拉取一次（5 分钟内不重复），也可手动刷新全部或单只；接口失败时可手动录入。
- **iOS 适配**：禁用双指缩放、安全区、毛玻璃底部标签栏、16px 输入防缩放、PWA 添加到主屏幕。
- **备份迁移**：导出 / 导入 JSON，数据不离开本机。

## 本地运行

```bash
# 任选其一
python3 -m http.server 8000
npm run serve
```

浏览器打开 <http://localhost:8000>。在 iPhone 上可通过同一局域网的电脑 IP 访问调试。

> 注意：ES Modules 不能通过 `file://` 直接打开，请使用本地 HTTP 服务。

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，将本目录文件推送到 `main` 分支。
2. 仓库 **Settings → Pages → Source** 选择 `Deploy from a branch`。
3. 分支选 `main`，目录选 `/ (root)`，保存。
4. 访问 `https://<用户名>.github.io/<仓库名>/`。

页面内所有资源均使用相对路径，可直接用于仓库子路径；`.nojekyll` 已包含，避免 Jekyll 处理静态资源。

## 使用流程

1. 在「策略」页对比普通 / 激进两套预置方案，选择全局默认并保存。
2. 在「持仓」页点右下角 `＋`，输入基金代码，点「查询名称与净值」或直接手动填写；可顺便登记初始底仓。
3. 点击基金卡片进入详情：查看规则锚点、分档补仓、补仓模拟器与交易流水。
4. 需要更新净值时点右上角刷新按钮；接口不可用时在详情页「手动录入净值」。
5. 定期在「数据」页导出 JSON 备份到网盘或本地。

## 计算口径

- 持仓份额：`Σ 买入份额 − Σ 卖出份额`
- 摊薄成本：`（Σ 买入金额 + 买入手续费 − 卖出对应成本）/ 剩余份额`
- 止损线：`平均成本 × (1 − 止损比例)`
- 止盈线：`平均成本 × (1 + 止盈比例)`
- 分档触发价：`底仓成本 × (1 − 档位跌幅)`；补仓后档位锚不变，只有止损/止盈线换锚
- 补仓后新成本：`（原成本 + 补仓金额）/ （原份额 + 补仓金额 / 成交净值）`
- 移动止盈：峰值净值达到止盈线后，当前净值回撤达到设定比例即提示
- 补仓批次收益：`当前净值 / 该笔补仓成交净值 − 1`
- 估值水平：`序列中 ≤ 当前值（最新收盘）的样本比例 × 100`；≤30 低估、30–70 正常、≥70 高估；样本 < 20 条不显示；债券收益率分位取反（收益率低=债贵）
- 当日买入市值：当日买入份额按成交净值（当日收盘净值）计算，不参与当日涨跌
- 三资产再平衡：`偏差 = 大类实际占比 − 目标占比`；`调仓金额 = 目标市值 − 实际市值`
- 美国实际利率（近似）：`US10Y − WTI 同比`（美国通胀预期无免费 CORS 接口，界面已标注）
- 期限利差：`长端收益率 − 短端收益率`，美国与中国均为 10Y−2Y（东财品种 171.US2Y / 171.CN2Y，界面已标注）

原文示例（10000 元 @1.000 + 1200 元 @0.900）得到摊薄成本约 0.988，止损线约 0.870，止盈线约 1.186，与策略中的 0.989 / 0.870 / 1.187 在展示精度内一致。

## 数据与隐私

- 数据存储键：`localStorage["fundpilot.v1"]`，不上传任何服务器。
- 净值来自东方财富公开接口 `fundmobapi.eastmoney.com`：进入持仓页时自动拉取一次（5 分钟内不重复），也可手动刷新。
- 估值水平标签按基金类型分流（债券/黄金/指数股票），基于东财 F10 基金类型与跟踪指数判定；接口失败或样本不足（< 20 条）时不显示，历史序列仅存内存缓存、不写入 localStorage。指数估值用价格分位近似（等价于常数盈利 PE 分位），主动/行业/QDII 基金不显示。
- 清除浏览器数据、换设备或使用无痕模式会导致数据丢失，请定期导出备份。
- 本工具只做规则提醒与成本记录，不自动下单，不构成投资建议。

## 已知边界

- 无账号与云同步，跨设备需手动导入/导出。
- 历史净值来自每次刷新的本地快照，首次使用时数据较少；移动止盈的峰值因此从首次使用后开始积累。
- 分红默认按「红利再投资」理解，按份额记账；现金分红可手动登记一笔买入份额或调整成本。
- 当日净值未公布时登记的交易为暂存状态（不参与持仓与收益计算），需待净值更新后自动确认；若登记日为非交易日（周末/节假日），将以下一交易日净值确认。
- 美国实际利率为近似口径（US10Y − WTI 同比），期限利差用 10Y−2Y，均已在界面标注；不构成投资建议。
- CPI/PPI/PMI 为月度数据（每月 9 日前后更新），当日内存缓存；接口失败时该卡片降级为「—」并在底部提示。
- 估值水平标签按基金类型分流（债券/黄金/指数股票）；接口失败或新基金样本不足（< 20 条）时不显示；主动/行业/QDII 基金暂无估值标签。
- **PWA 离线可用**：支持「添加到主屏幕」全屏运行，静态资源 Service Worker 缓存（cache-first），应用更新在第二次加载后生效；接口数据仍需在线
- 三资产自动归类依赖东财 F10 接口：识别失败时保持原大类（缺省权益），下次进入持仓页自动重试；货币基金目前归入权益大类。
- 宏观数据源带三级兜底：东财 push2 镜像域名 → JSONP 桥接 → 天天基金估值代理（仅黄金/原油/沪深300 日涨跌）；兜底生效时页面底部显示降级提示。
- 第三方接口可能调整或限制访问，届时应用自动降级为手动录入。
